## 履历展开布局迭代（等高 vs 独立高度）
- 问题1：点击倒三角展开子框 → grid 行变高 → 前两个栏目下边框一起下移（align-items: stretch 等高导致）
- 尝试：加 .tl-independent（align-items: start）→ 但用户反馈不展开时实习经历框下边缘比前两个低（多了按钮高度）
- 最终方案：恢复 stretch 等高 + 按钮/子框**绝对定位脱离文档流**（.timeline-expand absolute bottom:14px，子框 max-height 0→240px 展开）→ 不展开三框等高对齐，展开时子框浮在底部空白处，不影响任何其他框
- 注意：.timeline-item 需 position: relative（已有）；容器 pointer-events: none + 按钮 auto（否则按钮点不到）；子框宽度 calc(100%-40px)
- 修改：styles/components.css（移除 tl-independent，重写 timeline-expand 为绝对定位）；preview.html 已重建

## 履历展开布局终版 v2（纯独立高度 + 按钮绝对定位）
- 用户反馈 v1（JS 锁定）仍有问题：①前两个栏目的底边太下（stretch 拉高）②收起时有一瞬间前两个跟着收回（锁定清除跳变）
- 彻底方案：.timeline 永远 align-items: start（独立高度，每条目按内容高度）；.timeline-item padding-bottom 74px 底部预留区；.tl-toggle 绝对定位 bottom:-40px（不占文档流高度）；.tl-detail 文档流展开
- 效果：三框各自内容高度、底边由内容决定（不再被网格拉伸）；展开/收起只有实习经历自身变化，前两框一像素不动、无跳变
- 修改：src/components/Timeline.jsx（移除 syncHeights/JS 锁定，还原简单 useState）、styles/components.css；preview.html 已重建

## 履历展开布局终版（JS 锁定高度）【已被 v2 取代】
- 需求迭代：①按钮下移不挡字 ②展开时实习经历下边缘向下扩、字在按钮下方 ③前两个框一像素都不动（三个完全独立）
- 问题链：stretch 等高→展开拉伸前两框；align-items:start→不展开下缘不齐；has-open 切换→前两框高度跳变
