## 用户数字命名照片放错目录（根 assets/ 而非 public/）
- 现象：用户给多个 project 文件夹加了数字命名照片（1.png、2.jpg 等），但构建/localhost 都不显示
- 根因：照片放进了根 assets/projects/（构建产物副本，代码不读），而非 public/assets/projects/（虚拟模块扫描的源目录）
- 处理：node 脚本把根 assets/projects/ 下的 png/jpg 复制回 public 源目录（缺失才复制，共 12 张：project-1×4、2×3、5×2、6×3）；重启 dev server 重新扫描 ✓；重建 preview.html
- 扫描结果：project-1 gallery 4 张、project-2 7 张、project-5 4 张、project-6 7 张
- 再次验证记忆：数字命名图（1.png 等）能被虚拟模块正常识别，只要放在 public 源目录；根 assets/ 是构建副本，放进去无效（会被 sync 逻辑忽略，因为只复制不读取）
- 教训：新图必须放 public/assets/projects/project-N/；根 assets/ 或 dist/ 都是产物目录
